## Feature: QueryBatch accepts nested projections, collection laterals and UNION queries

v0.4.49's `QueryBatch` rejected nested-object selections at `add*` time and could
not register union queries, which excluded exactly the statements batching helps
most — wide aggregate/dashboard projections. Both limits are lifted; batched
results remain byte-identical to standalone execution.

### Nested-object selections

The rejection existed because the JSON-row reviver only walked top-level
selection keys: a `timestamp`/`date`/`decimal`/`bigint` leaf inside a nested
projection (`select(o => ({ meta: { createdAt: o.createdAt } }))`) would have
arrived as an unrevived JSON string. The reviver now recurses through nested
selection objects and registers revivals under the flat path-encoded aliases the
SQL actually returns (`__nested__meta__createdAt`), running BEFORE nested
reconstruction — so nested leaves get driver-equivalent types and the existing
transform pipeline (which always supported nested reconstruction for futures)
does the rest. Recursion enters plain object literals only; collections,
`SqlFragment`s and subquery builders are never walked.

### Collection (json_agg lateral) selections

Never gated, now covered by fidelity tests: `row_to_json` nests a lateral's json
column as a real array/object exactly like the driver's json parsing does, and
collection mappers run in the shared transform. Verified identical to standalone
`toList()` including ordering inside collections.

### UNION / UNION ALL queries

`UnionQueryBuilder.future()` is new: same `buildSql()` pass as `toList()`
(per-branch parameters merged and renumbered by the batch), first-leg metadata
drives post-processing and JSON revival — correct because UNION semantics force
every leg to project the identical column shape. A union registers via
`batch.addList(...)` like any other query and rides the same single round trip.

### Files Changed

- `src/query/query-builder.ts` — `collectJsonRowRevivals()` recursive reviver;
  `_buildUnionJsonRowReviver()` internal union hook
- `src/query/query-batch.ts` — nested-selection rejection removed
- `src/query/union-builder.ts` — `future()`; `UnionLegBuilder` reviver hook
- `tests/queries/query-batch.test.ts` — nested (incl. Date/decimal leaves),
  navigation-nested, collection-lateral and union fidelity tests (18 total)
